# Records

The conversation of record. Each file is a meeting transcript ingested with `parley ingest`, one utterance per line:

    **u012** [00:14:03–00:14:20] **Ana Ruiz:** Net thirty is fine for us.

Cite an utterance as `records/<file>.md#u012`.
Records are added in their own PR, before anything cites them, and are never edited after they merge.
Machine transcripts get names and words wrong; the person who ingests a record confirms who is who.
Agents never write records.
